# 이화첵 (첫 번째 개발 단위)

다전공 학생이 학번·다전공 유형·주전공·다전공 전공을 고르면, 해당 졸업요건 **공식 원문의 위치·이동 경로·출처·기준 시점**을 안내하는 웹 서비스입니다.
학점 계산·요약·자격 판정은 하지 않습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 생성 (정적 파일, 서버 불필요)
```

## 이번 단위에 포함된 화면

| 경로 | 화면 (Figma) |
|---|---|
| `/select` | 전공 조합 선택 화면 |
| `/result` | 졸업요건 안내 결과 화면 |
| `/go` | 외부 공식 원문 페이지 (새 탭으로 원문을 열고 이 화면 표시) |
| `/none` | 원문 없음 안내 화면 |

다음 단위: 홈/서비스 소개, 저장된 조합 확인, 다전공 신청 정보(Should), 장학금(Could).

## 데이터 수정 방법

모든 원문 정보는 `src/data/sources.json` 한 파일에 있습니다.

- `majors[].asMain` / `asSecond.{double|minor}`: 그 전공에 연결할 원문 id 목록. **첫 번째가 카드의 대표 원문**, 나머지는 "함께 확인할 공식 원문".
- `sources.{id}.basis`: 원문에 **적혀 있는** 적용 학번 구간. 원문에 연도가 없으면 `null` → 화면에 "기준 시점 미확인" 표시.
- 원문 내용이 바뀌면 이 파일을 고치고 `meta.lastChecked` 날짜를 갱신한 뒤 다시 배포합니다.

현재 등록: 경영학부, 컴퓨터공학과 (2026-10-11 실사이트 확인). 연계·융합전공은 미등록 → 원문 없음 화면.
